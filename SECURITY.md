# Security Policy

## Supported Versions

This repository is an educational codebase. Security fixes are prioritized for the `main` branch.

| Version | Supported |
| ------- | --------- |
| main    | Yes       |
| Older snapshots | No |

## Reporting a Vulnerability

Please do not open public issues for sensitive vulnerabilities.

1. Share a private report with reproduction steps, affected files, and impact.
2. Include compiler/platform details and minimal proof-of-concept.
3. Allow reasonable time for triage and remediation before public disclosure.

## Scope Notes

- Most examples are local desktop/console programs and do not expose network services.
- Secure coding issues are still treated seriously, especially unsafe input handling and memory/threading correctness.
